เชื่อมต่อแหล่งข้อมูล
  1. สร้าง Google Sheet ใหม่ → ไฟล์ → นำเข้า → อัปโหลด data/games.csv (หรือ steam_real.csv)
  2. กด แชร์ → ตั้งเป็น "ทุกคนที่มีลิงก์ - ผู้มีสิทธิ์อ่าน" (ไม่ต้อง Publish to web)
  3. คัดลอกลิงก์มาวางด้านบน แล้วกด "เชื่อมต่อ" — เพิ่ม/แก้แถวใน Sheet แล้วแดชบอร์ดจะอัปเดตเองตามรอบเวลา
  4. คอลัมน์ที่ต้องมี: name primary_genre release_date owners_estimate review_pct success (คอลัมน์อื่นมีหรือไม่มีก็ได้ กราฟที่ขาดข้อมูลจะซ่อนเอง)
  1. อัปโหลด CSV ขึ้น GitHub แล้วกดปุ่ม Raw คัดลอกลิงก์ (https://raw.githubusercontent.com/...)
  2. ทุกครั้งที่ commit ไฟล์ใหม่ แดชบอร์ดจะดึงข้อมูลล่าสุดเองตามรอบเวลา (GitHub อาจแคชไว้ ~5 นาที)
