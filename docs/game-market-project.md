# 🎮 คู่มือโปรเจค: วิเคราะห์ตลาดเกมบน Steam

## 1. ภาพรวมโปรเจค

**ชื่อโปรเจค (ตัวอย่าง):** การวิเคราะห์ตลาดเกมบนแพลตฟอร์ม Steam เพื่อสนับสนุนการตัดสินใจพัฒนาเกมของสตูดิโออินดี้
*Steam Game Market Analysis for Indie Studio Decision Making*

**โจทย์ธุรกิจ:** สตูดิโอเกมอินดี้ไทยมีงบจำกัด ต้องเลือกว่าจะสร้างเกมแนวไหน ตั้งราคาเท่าไร และควรมีฟีเจอร์อะไร เพื่อให้มีโอกาสประสบความสำเร็จมากที่สุด

**ผู้ใช้ผลการวิเคราะห์ (Stakeholder):** Game producer / ผู้บริหารสตูดิโอ / นักลงทุน

## 2. คำถามทางธุรกิจและวิธีตอบ

| # | คำถาม | ตัวชี้วัด / วิธีวิเคราะห์ | กราฟที่ใช้ |
|---|---|---|---|
| Q1 | ตลาดเติบโตและแข่งขันสูงขึ้นแค่ไหน? | จำนวนเกมใหม่ต่อปี, % เติบโต, มัธยฐานผู้เล่นต่อเกม | Bar + Line |
| Q2 | แนวเกมไหนน่าลงทุน? | จำนวนเกม (การแข่งขัน) vs อัตราฮิต, มัธยฐานรายได้ | **Opportunity matrix** (Bubble) |
| Q3 | เกมอินดี้ควรตั้งราคาเท่าไร? | รีวิวเฉลี่ย / มัธยฐานรายได้ / อัตราฮิต ตามช่วงราคา | Bar |
| Q4 | รายได้กระจุกตัวแค่ไหน? | สัดส่วนรายได้ Indie/AA/AAA, Top 1%/10% share | **Pareto curve** |
| Q5 | F2P คุ้มกว่าขายขาดไหม? | มัธยฐานผู้เล่น, รีวิว, รายได้ต่อผู้เล่น | ตาราง / Bar |
| Q6 | ปัจจัยอะไรสัมพันธ์กับเกมฮิต? | อัตราฮิตแยกตามฟีเจอร์ เทียบค่ารวม (percentage points) | Diverging bar |

**นิยาม "เกมฮิต" (Hit):** รีวิวเชิงบวก ≥ 80% **และ** ผู้เล่น ≥ 100,000 คน
(เขียนนิยามให้ชัดในรายงาน และอธิบายว่าทำไมเลือกเกณฑ์นี้ เช่น อ้างอิงระดับ "Very Positive" ของ Steam)

## 3. ข้อมูล

### แหล่งข้อมูล (เลือก 1 ทาง)
| ทางเลือก | เหมาะกับ | วิธีได้มา |
|---|---|---|
| **A. ชุดเดโม่** `data/games.csv` | ฝึก / ทำต้นแบบ / สอบนำเสนอเร็ว | มีอยู่แล้ว (ข้อมูลสังเคราะห์ ต้องระบุในรายงาน) |
| **B. SteamSpy API** (แนะนำ) | ข้อมูลจริง ล่าสุด | `python scripts/fetch_steam_data.py --pages 1 --details 500 --release` → `data/steam_real.csv` |
| **C. Kaggle** | ข้อมูลจริงจำนวนมาก ไม่ต้องเขียนโค้ดดึง | [Steam Games Dataset](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset), [Steam Store Games](https://www.kaggle.com/datasets/nikdavis/steam-store-games) |

แหล่งเสริม: [SteamDB](https://steamdb.info) (ตรวจสอบตัวเลข), [VGChartz Video Game Sales](https://www.kaggle.com/datasets/gregorut/videogamesales) (เปรียบเทียบคอนโซล), [RAWG API](https://rawg.io/apidocs) (คะแนน/แพลตฟอร์ม)

> 💡 ถ้าอยากได้คะแนนเพิ่ม: ใช้ **B** ดึงข้อมูลจริง แล้ว **เทียบผลกับชุดเดโม่** หรือเปรียบเทียบข้อมูลต่างปี

## 4. ขั้นตอนทำงาน + เครื่องมือในโปรเจคนี้

| ขั้นตอน | ทำที่ไหน | ผลลัพธ์สำหรับรายงาน |
|---|---|---|
| 1. สำรวจข้อมูล (EDA) | เว็บแอป → แท็บ 🔍 โปรไฟล์ข้อมูล | ตารางสถิติ, ค่าว่าง, outlier |
| 2. ทำความสะอาด | เว็บแอป → 🧹 หรือ notebook ส่วนที่ 1 | Cleaning log |
| 3. วิเคราะห์เชิงลึก | `analysis/game_market_analysis.ipynb` | กราฟใน `analysis/figures/` (ใส่รายงานได้ทันที) |
| 4. แดชบอร์ด | เว็บแอป 📈 หรือนำ `analysis/output/*.csv` เข้า **Power BI** | แดชบอร์ด 1–2 หน้า |
| 5. สรุป Insight | เว็บแอป 💡 + notebook ส่วนที่ 8–9 | บทที่ 5 |

**เคล็ดลับการวิเคราะห์ข้อมูลเกม:**
- ยอดผู้เล่นและรายได้ **เบ้ขวามาก (long tail)** → ใช้ **มัธยฐาน** แทนค่าเฉลี่ย, พล็อตด้วย **log scale** (เว็บแอปมีปุ่ม Log scale ในแท็บ 🛠️)
- ใช้ **Spearman correlation** แทน Pearson เมื่อข้อมูลเบ้
- ระวัง **ตัวแปรกวน** เช่น เกมรองรับภาษาไทยมักเป็นเกมทุนสูงอยู่แล้ว → แยกวิเคราะห์เฉพาะ Indie
- ระวัง **time bias** เกมเก่ามีเวลาสะสมผู้เล่นนานกว่าเกมใหม่

## 6. ผลการวิเคราะห์จากชุดเดโม่ (ตัวอย่าง — ต้องคำนวณใหม่ถ้าใช้ข้อมูลจริง)

- เกมใหม่ต่อปีเพิ่มจาก 141 (2016) เป็น 337 (2025) แต่ **มัธยฐานผู้เล่นต่อเกมลดลง** → แข่งขันสูงขึ้น
- **Roguelike** อัตราฮิตสูงสุด 12.7% ขณะที่มีเกมเพียง ~5% ของตลาด; **Casual / Puzzle** อัตราฮิตต่ำสุด (~4%)
- เกม **top 10% ครองรายได้ 95.9%** — ตลาดแบบ hit-driven, Indie คิดเป็น 79% ของเกมแต่ได้รายได้เพียง 2.8%
- เกมอินดี้ราคา **< $5 มีมัธยฐานรายได้ต่ำสุด** — ตั้งราคาถูกไม่ได้ช่วยให้ขายได้มากขึ้นอย่างคุ้มค่า
- เกมรองรับ **ภาษาไทย** มีอัตราฮิตสูงกว่า (9.0% vs 5.5% แม้ดูเฉพาะ Indie); **Early Access** อัตราฮิตต่ำกว่า (3.3%)
