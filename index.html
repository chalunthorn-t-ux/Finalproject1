เครื่องมือวิเคราะห์ข้อมูลสำหรับโปรเจคจบสาย Data Analyst

โหลดข้อมูลเดโม่ หรืออัปโหลดไฟล์ CSV ของคุณเอง แล้วทำครบ workflow: สำรวจ → ทำความสะอาด → วิเคราะห์ → สร้างแดชบอร์ด → สรุป Insight

1. เลือกชุดข้อมูลเดโม่

2. หรืออัปโหลดไฟล์ของคุณ

Workflow ของโปรเจค

  1. ตั้งคำถามธุรกิจ — เช่น "ช่องทางไหนทำกำไรสูงสุด?" "ทำไมพนักงานลาออก?"
  2. โปรไฟล์ข้อมูล — ดูชนิดคอลัมน์ ค่าว่าง ค่าผิดปกติ
  3. ทำความสะอาด — ลบแถวซ้ำ จัดการค่าว่าง กรองข้อมูล
  4. วิเคราะห์ — Pivot, กราฟ, ความสัมพันธ์ระหว่างตัวแปร
  5. แดชบอร์ด + Insight — สรุปผลและข้อเสนอแนะ แล้ว Export ไปใช้ในรายงาน

ความสัมพันธ์ระหว่างตัวแปรตัวเลข (Correlation)

ค่าใกล้ +1 = ไปทางเดียวกัน, ใกล้ −1 = สวนทางกัน, ใกล้ 0 = ไม่สัมพันธ์เชิงเส้น

ประวัติการทำความสะอาด (Cleaning log)

นำไปเขียนในบท "การเตรียมข้อมูล" ของรายงานได้เลย

    Insight ที่ระบบค้นพบอัตโนมัติจากข้อมูลปัจจุบัน — ใช้เป็นจุดเริ่มต้น แล้วตรวจสอบ/อธิบายเหตุผลเพิ่มเองในรายงาน

    แหล่งข้อมูลจริงที่นำมาใช้ทำโปรเจคได้ — ดาวน์โหลดเป็น CSV แล้วอัปโหลดในหน้า "เริ่มต้น"
